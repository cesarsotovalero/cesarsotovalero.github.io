# Unpublished files

Files in this folder are kept in the repository but are not part of the website.
Jekyll skips folders whose names start with an underscore, so nothing here is built or served.

The repository itself is public, so these files can still be read on GitHub.

- [`projects-roadmap/`](projects-roadmap/README.md): ten open-source projects for investment banking and private equity (Markdown and PDF).
- `blog-notes/`: writing notes that used to sit in `_posts/` (post ideas, quotes, an essay guide, and the `gh-md-toc` helper script).
